Como ler uma lei

O verbo principal de uma norma diz o que ela faz. “Criar” não é o mesmo que “instituir”; “revogar” não é o mesmo que “alterar”. Use este guia para saber o que esperar antes de abrir o texto.

1. Verbo
O que a norma cria, muda ou interrompe.
2. Sujeito
Quem pratica a ação: Câmara, Prefeitura, Mesa ou servidor.
3. Efeito
Se vale para todos, para um órgão ou só para uma pessoa.

O verbo não decide sozinho

Uma indicação pode pedir a mesma coisa que um projeto de lei, mas não tem o mesmo efeito. Um requerimento cobra informação; uma moção manifesta posição; um projeto de lei propõe uma regra nova. Por isso o tipo da norma e o verbo aparecem juntos no site.

Dica: comece pela ementa, confira o tipo e depois leia o artigo que começa com o verbo principal.
